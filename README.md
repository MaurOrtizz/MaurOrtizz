### 🌟 Featured Projects

#### [AtlasShift](https://github.com/MaurOrtizz/AtlasShift)

An interactive political map editor for creating alternate worlds. It allows users to redraw borders, create and merge countries, edit territories, and import or export geographic information in GeoJSON format.

**Technologies:** React, TypeScript, Vite, MapLibre GL, Turf.js, FastAPI, SQLModel, SQLite, Docker, and GitHub Actions.

#### [ANCLA — HackMTY 2026 Capital One Challenge](https://github.com/Team-Aseorias/HackMty2026-CapitalOne)

A team project developed for HackMTY 2026. ANCLA is a recommendation engine that compares the expected costs of allowing a purchase or requesting additional verification, balancing fraud risk, operational cost, and checkout friction.

The project provides explainable recommendations, configurable security limits, historical feedback, policy evaluation, and integrations with MongoDB Atlas and the Capital One Nessie API.

**Technologies:** Python, FastAPI, React, TypeScript, Node.js, MongoDB Atlas, scikit-learn, NumPy, SciPy, and Render.

#### [Data Mining 2025](https://github.com/MaurOrtizz/MineriaDatos2025)

An academic data mining project focused on the analysis of global demographic information. It covers the complete data workflow, from collection, cleaning, transformation, and visualization to statistical testing and machine-learning applications.

The repository includes descriptive statistics, Shapiro-Wilk tests, ANOVA, linear regression, K-Nearest Neighbors, K-means, DBSCAN, PCA, demographic forecasting, and text analysis using word clouds.

**Technologies:** Python, pandas, NumPy, Matplotlib, Seaborn, SciPy, statsmodels, scikit-learn, WordCloud, and the Kaggle API.
